立项前未决问题

这些问题来自附件证据不足、Palantir 产品边界和目标平台落地假设。答案会改变范围、SLO、权限或数据模型，应在采购/开发承诺前关闭。

1. 业务与范围

  1. 首个可交付业务闭环是数据投研、组合运营、风险，还是含实盘下单？
  2. 现有 OMS/IMS/RMS/Algohub/UFT 哪些保留，哪些只集成，哪些替换？
  3. 哪些页面是正式业务流程，哪些只是个人工作台或临时报表？
  4. 行业周期研究等停用能力应只读归档、迁移还是退役？
  5. 客户、TRS、客服、学习中心和私有云是否在本项目范围？

2. 对象、规则与算法

  1. 产品—组合—策略—资金账号—资产单元—子账户的权威基数和生命周期是什么？
  2. 订单、成交、持仓、划拨的主键、序列号、状态码、修订和对账真源是什么？
  3. VMAP 是否为 VWAP，附件中的无标题列和 b/s/bs/d 字段分别是什么？
  4. 金额、价格、数量、BP、汇率和时间戳的精度、单位、币种与时区是什么？
  5. 因子正式公式、发布时间、复权、样本空间、不可成交、成本和样本外规则是什么？
  6. SS/S/AA/A/B/T 评级、二阶段 PB 与 AI 景气阈值的正式口径、owner 和审批是什么？

3. 身份、安全与合规

  1. 组织、法人、基金、部门、策略、账户和客户的行/列/动作权限如何继承？
  2. 谁可提交、审批、交易、冻结、发布、分享、导出和紧急解除？
  3. 是否处理重要数据、核心数据、敏感个人信息、MNPI、PCI 或跨境访问？
  4. 经营主体是否被认定为 CII，等保等级、密评和行业监管报送要求是什么？
  5. 原附件的秘密轮换、泄露调查、个人信息处置和 legal hold 是否完成？
  6. 外部行情、研报、WIND/Level-2、竞品数据及模型的许可允许哪些存储、派生、AI 和再分发？

4. 规模与可靠性

  1. 标的、账户、组合、用户、订单/成交/Tick 日峰值与三年增长是多少？
  2. 盘前、盘中、盘后各路径的 P50/P95/P99/P99.9 延迟和超时策略是什么？
  3. 交易、账本、风险、投研、报告的可用性、RTO、RPO 和数据恢复点是什么？
  4. 同城双活/灾备、两地三中心、专线、柜台/交易所连接和断网降级要求是什么？
  5. 历史行情、文档、图片、音频和视频的年增量、热/冷层和保存期是什么？

5. Palantir/平台采购 PoC

  1. 实际许可证、enrollment、部署主权、数据驻留、容量和支持 SLA 是什么？
  2. Interface、Derived Property、Custom Endpoint、Streaming、Scenario、Media delete 在目标环境的实际支持与限制是什么？
  3. OSDK、Action、Object/Property Security、Materialization、Webhook 在真实金融数据量下能否达到验收？
  4. 能否导出本体、数据、审计和应用契约，避免不可接受的退出锁定？
  5. Apollo/Marketplace/Release Channel 如何与组织现有 CI/CD、审批和多环境模型对接？

6. 关闭机制

每项分配业务 owner 和关闭日期；结论进入 ADR、数据契约、本体版本或政策。若到实施门仍未关闭，必须降低范围、采用保守默认或阻断上线，不能把关键未知留给开发临场判断。
