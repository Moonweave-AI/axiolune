统一工作台、数据与资讯

1. 统一工作台

1.1 角色首页

根据用户角色、团队、产品/账户范围和当前环境提供：

  • 待审批、待复核、待处理异常；
  • 重要风险、策略/算法状态和系统状态；
  • 自选对象、最近访问、保存视图和订阅；
  • 市场概览、投资日历和数据新鲜度；
  • 正在运行的研究、报告、导出和工作流；
  • 个性化但受管理员约束的布局。

默认模板按研究、基金经理、交易员、风控、产品、数据和运维岗位提供。用户布局不改变指标定义和权限。

1.2 分享方案

“分享方案”不保存一张截图，而是保存：

  • 对象范围与过滤；
  • 指标/列/图表配置；
  • 时间与场景；
  • 数据和本体版本；
  • 访问策略和到期；
  • 所有者、协作者、评论和引用；
  • 可选的快照与实时视图。

黑灰名单监控、策略监控和市场总览成为内置方案模板。

1.3 任务与协同

  • 对象关联评论、@提及、附件和决策记录；
  • Action/Workflow 自动生成任务；
  • SLA、负责人、观察者、升级和到期；
  • 从任务直接进入相关对象和证据；
  • 分享遵守对象权限，不通过复制数据绕过权限。

2. 实时资讯

2.1 财经新闻

功能：

  • 多来源接入、去重、聚类与原文保留；
  • 发布时间/采集时间/修订时间；
  • 证券、公司、行业、主题和事件候选链接；
  • 来源等级、版权、语言、情感/影响候选；
  • 关键词、语义、本体和时间组合检索；
  • 订阅、提醒、收藏、评论和研究项目引用；
  • 原文、抽取声明和人工确认分离。

2.2 互动问答

问答基于权限感知检索，回答：

  • 引用具体文档片段或对象属性；
  • 显示数据时间与来源冲突；
  • 支持追问、对象跳转和保存为研究笔记；
  • 不把模型回答直接写成事实；
  • 对数据不足、无权限或时间不一致明确拒答。

3. 投资日历

统一展示：

  • 财报预告/披露、股东大会、分红、解禁、停复牌；
  • 指数调整、合约到期、换月与交割；
  • 宏观数据、政策、行业会议和内部任务；
  • 研究报告、模型、风险例外和产品发布到期；
  • 市场时区、来源、置信和修订。

日历事件可关联 Instrument、Issuer、Portfolio、ResearchProject 和 Action，并支持订阅、影响范围和历史变化。

4. 行情与 Level-2

4.1 行情工作台

  • 自选列表与多市场代码解析；
  • 分时、K 线、成交量、盘口和逐笔；
  • 复权/不复权、频率、交易时段和来源；
  • 公司行动和事件叠加；
  • 多标的/指数/基准对比；
  • 数据延迟、缺口、备用源和回补状态；
  • 点击点位进入对应事件/订单/成交/证据。

4.2 Level-2

  • 十档/多档盘口；
  • 逐笔委托与逐笔成交；
  • 主动买卖、订单流、撤单、队列和大单指标；
  • 交易所序号、丢包、乱序和延迟；
  • 按权限与数据许可限制导出和历史范围。

Level-2 指标均注册为函数，不在前端临时计算生产口径。

5. 期指基差

四个视图对应附件需求：

  • 套利分析；
  • 贴水/升水差值；
  • 年度对比；
  • 合约对比。

可选现货代理、期货合约、滚动窗口、0.5–3σ 阈值、年化方法、到期日和交易成本。计算结果关联 BasisObservation、Contract、Index、MetricVersion 与数据快照；换月与缺失处理必须显式。

6. 数据目录

将原“数据集市”和“数据字典”合并为一个目录：

  • 业务视图：按对象、指标、场景搜索可用数据；
  • 技术视图：Schema、分区、格式、样例、管线和使用；
  • 治理视图：所有者、分类、质量、SLO、血缘、权限和保留；
  • 产品视图：适用场景、服务级别、成本、申请和反馈。

用户能从页面字段进入对应 Property/Metric/DataAsset，也能从目录查看下游应用和报告。

7. 基础/主数据

附件中的基金产品、资金账号、资产单元、券商/网关和板块成分统一进入 Master Data：

  • 产品主数据；
  • 资金账户与外部账户映射；
  • 资产单元与产品/账户层级；
  • 券商、柜台、网关、算法商及能力；
  • 证券、市场、币种、交易日历；
  • 行业、指数、板块及点时成分；
  • 标识冲突、合并、审批与有效期。

所有更正通过动作完成；重要主数据提供双人复核和影响分析。

8. 核心对象、函数与动作

类型 内容
对象 NewsItem、Document、Claim、Evidence、CalendarEvent、Instrument、Quote、Trade、OrderBookSnapshot、DataAsset、FundProduct、Account、AssetUnit
函数 NormalizeIdentifier、ClusterNews、CalculateBar、CalculateBasis、AssessFreshness、ResolveDataSource
动作 SubscribeObject、ShareView、ApproveClaim、CorrectMasterData、RequestDataAccess、SwitchMarketDataSource

9. 验收重点

  • 同一证券从新闻、行情、日历和主数据进入同一对象；
  • 任一图表数字可查看定义、来源和时间；
  • 断线/延迟/备用源状态可见；
  • 数据目录不再维护两套重复字段；
  • 无权用户不能通过搜索、分享、导出或 Agent 获取对象；
  • 分享方案在数据/指标版本变化时显示差异和失效提醒。
