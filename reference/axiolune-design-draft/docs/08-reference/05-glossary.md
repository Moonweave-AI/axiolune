# 术语表

| 术语 | 定义 |
| --- | --- |
| Ontology / 本体 | 把业务对象、关系、逻辑、动作、安全和证据统一为可运行契约的系统层，不等同于图数据库 |
| Object type | 真实实体或事件的类型定义，如 Instrument、Order、RiskAlert |
| Object | Object type 的实例，具有稳定标识、属性、关系和时间语义 |
| Link type | 两类对象之间可导航、可授权、可带时间/证据的业务关系 |
| Interface | 可由多类对象组合实现的共享能力约束，不是深继承树 |
| Value type | 带格式、精度、单位、校验和版本的业务值，如 ISIN、Money、BasisPoints |
| Function | 可版本化、可测试、无或有限副作用的业务计算 |
| Action | 被授权、校验、审计的业务动词；可改变对象并触发受控副作用 |
| Policy | 决定读取、动作或数据使用是否允许的版本化规则 |
| Scenario | 与主状态隔离的业务 What-if 覆盖层 |
| Branch | 对本体、代码、规则和契约进行开发变更的隔离分支 |
| Evidence | 支持事实、推导或决定的可定位来源及完整性信息 |
| Bitemporal | 同时记录业务有效时间与系统记录时间 |
| Point-in-time | 查询/计算只使用当时已经可知的数据与当时有效的实体集合 |
| Projection | 从事实源派生、可重建的搜索、图、向量、OLAP 或 UI 读模型 |
| Data product | 有 owner、契约、质量、SLO、权限、血缘和生命周期的数据资产 |
| Outbox | 与业务事务同库提交、随后可靠发布事件的模式 |
| Saga | 通过可恢复步骤和补偿协调跨系统长事务的模式 |
| Idempotency key | 识别同一动作重试并防止重复副作用的稳定键 |
| Maker-checker | 提交者与审批者分离的四眼控制 |
| ABAC / ReBAC | 基于属性 / 基于关系的授权模型 |
| RLS | 数据库行级安全，作为服务端策略的纵深防御 |
| SLI / SLO | 可测量服务指标 / 对指标的目标 |
| RTO / RPO | 故障后恢复时限 / 可接受数据丢失时点 |
| TCA | 交易成本分析，比较成交与到达价、VWAP、TWAP 等基准 |
| IC / RankIC / ICIR | 因子与未来收益的相关、秩相关及其稳定性指标 |
| VaR / CVaR | 给定置信度下的损失分位与超过分位后的平均尾部损失 |
| GraphRAG | 用实体关系图辅助检索、上下文组织和可引用回答的 RAG 方法 |
| MNPI | 重大非公开信息，需要严格用途、隔离和审计 |
