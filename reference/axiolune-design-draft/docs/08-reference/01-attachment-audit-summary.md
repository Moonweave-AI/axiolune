## 2. 对架构有决定性的发现

1. 材料是页面清单、截图、局部字段、两份导出和编译资产的集合，并非完整需求规格。
2. 业务横跨工作台、数据资讯、交易风控、量化投研、主动投研、产品/经营报表，另有学习、私有云、系统与运营入口。
3. UI 并存黑底行情终端、深色 OMS/IMS、浅色企业工作台、独立 AI 仪表盘四套视觉语言。
4. 两份导出分别为 2,474×20 的委托数据和 802×30 的持仓数据；暴露超大整数 ID、毫秒时间戳、未解释枚举、单位写入列名、0/空值混用和全空目标字段。
5. 嵌套资产可确认 Umi 4.3.20、React 17.0.2、DVA、Ant Design/Pro Layout、DevExtreme、ECharts、Chart.js 4.4.1、Axios 0.27.2、WebSocket 和微前端线索。
6. 现有材料含高风险明文秘密、内部端点、人工运维命令和个人信息；必须视为安全事件输入，而不能原样进入设计或代码。

## 3. 迁移结论

- 复用业务术语、用户任务、页面字段候选和已验证交互，不复制页面级数据孤岛。
- 以 `对象—关系—函数—动作—策略—证据—权限—事件—视图` 重组功能。
- Umi/React 17 页面采用绞杀式迁移：旧路由接入统一身份和导航，新领域包逐页替换；不先拆成大量微前端。
- 通用 SQL 接口替换为受策略约束的 Object Query/Action API。
- OMS/IMS 快照和柜台回报转为不可变事件 + 当前状态投影；19 位 ID 全链路使用字符串。
- AI 静态仪表盘改为有来源、数据时间、阈值版本和证据引用的动态指标产品。

## 4. 必须在实施前补齐的访谈

- 用户、组织、产品、组合、账户、资产单元的权限继承；
- 可交易、可发布、可导出动作的审批与审计；
- 数据源许可、频率、修订、质量和保存期；
- 订单/成交事件序列、枚举、精度、币种、时区与纠错；
- 因子定义、点时口径、成本、样本外与复现；
- 真实吞吐、尾延迟、RTO/RPO、灾备和降级目标；
- 停用行业研究、外链/iframe、旧报表的归档或退役；
- 非结构化内容的版权、恶意文件检测、OCR、转码、保留和删除。
