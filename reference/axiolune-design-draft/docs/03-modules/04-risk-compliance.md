# 风险、合规与核对

## 1. 风险分层

| 阶段 | 目标 | 示例 |
| --- | --- | --- |
| 交易前 | 阻止非法或超限动作 | 资金/持仓、限额、禁买卖、涨跌停、集中度 |
| 交易中 | 发现状态和行为异常 | 撤单率、拒单、参与率、延迟、价格偏离 |
| 交易后 | 评估结果、暴露和违规 | TCA、敞口、对账、规则回放 |
| 场景 | 评估潜在变化 | 目标组合、冲击、压力、规则变更 |
| 模型/数据 | 确保风险输入可信 | 新鲜度、缺失、漂移、来源切换 |

## 2. 风险规则中心

股票和期货风险配置统一为版本化 `RiskRuleSet`：

- 规则名、类型、目标对象、市场和账户范围；
- 硬阻断/警告/审批/记录；
- 阈值、单位、窗口和优先级；
- 依赖指标和数据新鲜度；
- 有效期、版本、所有者和审批；
- 测试样例、历史回放和影响；
- 冲突与组合逻辑；
- 紧急停用与回滚。

规则变更先在历史事件和当前场景分支运行，比较新增阻断、漏报和延迟。

## 3. 股票/期货实时风险监控

附件字段按层次展示：

- 账户：委托笔数、委托额、成交额；
- 撤单：笔数、撤单率、撤单拒绝；
- 风险：警告、阻断、例外、场外委托；
- 基础设施：柜台、网关延迟、风控延迟；
- 衍生：集中度、杠杆、保证金、敞口、流动性。

每个告警可以展开查看触发事件、规则版本、输入、阈值、账户/组合/订单、影响和建议动作。

## 4. 风险标的与黑灰名单

`WatchlistEntry` 连接标的、名单类型、来源、理由、证据、适用动作、有效期、负责人和状态。

- 黑名单：默认阻断明确动作；
- 灰名单：警告、限制或审批；
- 观察名单：监控但不自动限制；
- 外部名单与内部研究名单分开；
- 标的代码变化、公司合并等通过 Canonical ID 延续；
- 加入、修改、解除和到期均是 Action；
- 批量导入先预览匹配和影响。

## 5. 快速风控

提供少量经严格授权的应急动作：

- 暂停账户/策略/算法；
- 禁止特定方向或标的；
- 限制参与率、数量或金额；
- 切换网关/数据源；
- 触发撤单或只减仓模式。

快速不等于无控制。动作需明确适用范围、TTL、二次确认、双人复核（按等级）、外部回执和自动复查；到期不应静默永久化。

## 6. 事后风险

- 组合与账户敞口、集中度、风格、行业、地域和币种；
- VaR/CVaR、压力、敏感度和流动性；
- 订单/成交违规回放；
- 撤单、拒单、场外、异常价格和最佳执行；
- 风险例外使用情况与结果；
- 数据/模型质量对风险结论的影响；
- 生成可追踪报告和整改任务。

## 7. 金葵花每日核对

附件中的“每日核对”升级为可配置 Reconciliation：

- 订单—成交；
- 成交—持仓；
- 持仓—托管/柜台；
- 资金—会计/银行；
- 净值—估值/会计；
- 目标—实际；
- 产品/账户/资产单元映射；
- 数据源行数、金额和哈希。

差异形成 `ReconciliationBreak`，具备类型、严重度、金额、来源、负责人、状态、原因和调整动作。调整不覆盖原值，保留证据。

## 8. 融券管理

- 券源、数量、费率、期限和供应商；
- 已借、占用、可用、归还和召回；
- 标的/账户/组合约束；
- 卖空订单与券源锁定；
- 费用、保证金和风险；
- 到期/召回提醒与处置；
- 来源、快照和对账。

## 9. 例外与审批

RiskException 包含：

- 对象/规则/动作；
- 申请原因和证据；
- 允许的范围；
- 开始/到期；
- 补偿控制；
- 申请、审批、复核和观察者；
- 使用事件和结果；
- 到期自动回收。

禁止永久“临时例外”；审批人不能与申请人相同，关键规则要求职责分离。

## 10. 风险事件生命周期

`Detected → Triaged → Assigned → Mitigating → Resolved → Verified → Closed`

错误告警标记 FalsePositive 并反馈规则，但不删除历史。重复告警可聚合为 Case，同时保留单个触发证据。

## 11. 验收重点

- 硬规则在数据缺失/过期时采用明确 fail-safe/fail-closed 策略；
- 规则版本和输入可重放；
- 风险动作不能绕过 Action Service；
- 快速限制有 TTL、审批和外部回执；
- 每日核对差异不会被“自动修平”而丢失证据；
- 黑灰名单在搜索、订单、批量导入和 Agent 工具中一致生效。
