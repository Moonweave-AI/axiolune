非功能需求与质量属性

1. 服务等级基线

能力 初始目标 说明
交易前硬风控判定 以柜台与网络预算反推；平台内关键路径 P99 需专项压测 不能用普通 Web API 目标代替交易时延目标
订单状态更新到监控 UI 正常负载 P95 ≤ 1 秒 明确来源时间、处理时间和显示时间
常规对象详情 P95 ≤ 500 ms 不含首次大规模图遍历
对象搜索/混合检索 P95 ≤ 1.5 秒 必须包含权限过滤
ClickHouse 交互分析 常用视图 P95 ≤ 3 秒 重查询异步化并展示进度
工作流动作提交 P95 ≤ 500 ms 返回已受理 外部执行异步可追踪
行情/交易核心能力可用性 99.95%–99.99% 按最终业务等级校准
研究与报表可用性 99.9% 允许计划维护

2. 正确性

  • 订单数量、成交数量、撤单数量和剩余数量遵守状态机不变量；
  • 资金、持仓、净值和风险指标有权威来源、计算版本和核对；
  • 所有研究结果可定位到点时数据快照；
  • 时间、币种、价格精度、复权和单位使用类型化值，不靠列名约定；
  • 最终一致视图显示数据时间与新鲜度，不伪装为即时真相；
  • 高风险动作使用乐观版本/ETag 防止陈旧写入。

3. 安全与隐私

  • MFA、短期令牌、工作负载身份、最小权限；
  • 对象、属性、动作和导出级控制；
  • 传输与静态加密，关键字段令牌化或列加密；
  • 秘密不得出现在仓库、镜像、配置明文、CSV、日志和前端；
  • 不可信文档与提示注入防护；
  • 访问、查询、导出、策略修改和动作执行全量审计；
  • 保留期、用途限制和删除流程可证明。

4. 可解释与可审计

任何数字或结论都能查看：

  • 定义和业务含义；
  • 输入对象与数据快照；
  • 算法/模型/规则版本；
  • 来源与证据；
  • 运行时间、参数和负责人；
  • 权限裁剪和缺失信息；
  • 历史版本和下游使用。

任何动作都能查看发起者、审批者、策略判定、变更前后、外部回执、失败与补偿。

5. 可扩展性

  • 数据表、Topic 和 ClickHouse 分区以时间与业务键组合，避免单热分区；
  • 在线对象查询支持批量、游标和投影字段；
  • 大结果使用异步任务、对象存储和短期签名下载；
  • 图查询限定路径深度、超时、节点预算和权限过滤；
  • 模型推理有配额、批处理、缓存和降级；
  • SDK 与 Schema 采用向后兼容规则，禁止隐式破坏下游。

6. 可维护性

  • 模块和服务有 CODEOWNERS、运行手册、SLO、依赖与版本；
  • API、事件、本体和数据契约进入 CI 兼容性检查；
  • 业务规则从 UI 和临时 SQL 中移入函数/规则注册；
  • 发布采用小批量、金丝雀、自动回滚和明确交易窗口；
  • 每个告警有负责人、严重度、运行手册和静默规则；
  • 不允许以人工 screen/crontab 和 kill -9 作为生产服务管理方案。

7. 可用性与体验

  • 所有高频操作支持键盘、保存视图、深链和批量处理；
  • 高密度表格使用虚拟滚动、列固定、列预设和服务端过滤；
  • 实时页面显示连接状态、延迟、数据时间和降级来源；
  • 颜色不是唯一状态信号，涨跌/风险同时使用符号与文字；
  • 长任务可取消、重试和查看阶段；
  • 权限不足显示原因与申请路径，不以空白页掩盖。

8. 可测试性

  • 领域状态机使用属性测试和模型测试；
  • 算法使用黄金数据、边界市场日和历史重放；
  • 数据管线使用契约、质量、回归和点时泄漏测试；
  • 权限使用主体—对象—动作矩阵和负向测试；
  • UI 使用视觉回归、可访问性、实时断线和大表性能测试；
  • 灾备、降级、备份恢复和外部超时通过混沌/演练验证。

9. 可移植与可退出

  • 业务数据使用开放格式和导出接口；
  • 所有本体和契约可导出；
  • 云服务通过适配器和 IaC 封装；
  • 商业组件记录许可、数据格式、替代品、迁移步骤和退出成本；
  • 不把供应商内部 ID 写入公开业务契约。
