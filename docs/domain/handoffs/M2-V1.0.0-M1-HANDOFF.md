# M2 v1.0.0 → M1 Materialization Handoff

**Title**: M2 v1.0.0 M1 Handoff  
**Description**: Canonical entry point for M1 real-data materialization work after M2 ontology engineering completion  
**Last Updated**: 2026-08-03  
**Status**: Active  
**Audience**: M1 implementers, ontology maintainers  
**Authority**: [ADR-017](../decisions/ADR-017-m2-v1-completion-and-m1-handoff.md)

## Overview

M2 finance domain **v1.0.0** is **approved** per [M2-REVIEW-ROUND-12](../decisions/M2-REVIEW-ROUND-12.md). Ontology YAML under `ontology/domain/finance/` is frozen for semantic IRIs; M1 work adds real table/column mappings, production ingest, and runtime gates — not M2 type renames without ADR.

## What M1 inherits (ready)

| Artifact | Location |
|----------|----------|
| 10 approved modules @ 1.0.0 | `ontology/domain/finance/*/module.yaml` |
| Module registry | `ontology/domain/finance/registry/module-registry.yaml` |

| Competency questions | `docs/ontology/competency-questions/` |

| Slice A replay runner | `scripts/domain/run-slice-a.cjs` |
| Regression smoke | `node scripts/domain/test-all-domain.js` |

## Explicit M1 scope (NOT done in v1.0.0)

- Real production table/column mapping (M2-PLAN §10.4)
- `artifactDigest` / byte-lock manifests / `references.lock.yaml`
- `run-release-capability` 21-gate production matrix

- Full custodian operational workflow automation

```bash
node scripts/domain/test-all-domain.js
node scripts/domain/run-all-cq-probes.cjs
node scripts/domain/run-slice-a.cjs

node scripts/domain/run-pyshacl-smoke.cjs
```
